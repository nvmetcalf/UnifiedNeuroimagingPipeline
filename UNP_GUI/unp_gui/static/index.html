3. Run on & submit

Runs the same job script with bash on the node this GUI runs on, detached, so it keeps going if you close the GUI — but it stops if this desktop / interactive session ends or hits its time limit. Logs, status, cancel and e-mail work as for Slurm jobs. The Slurm resources below are ignored.
One sbatch job per subject/session. P2 runs the selected modules in order and stops that subject at the first failing module. Jobs are submitted through sg <group> with umask 002 so outputs belong to the lab group.
